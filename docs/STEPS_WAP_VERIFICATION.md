# 歩数 CSV（WAP 動作確認手順）

対象サンプルは **2026年9月** の日付です。カレンダーで **2026年9月** を表示した状態で確認してください。

## サンプルファイル

| ファイル | 用途 |
|----------|------|
| `/fixtures/steps_daily.sample.csv` | 最小セット（9/1〜9/7）・手順 A の基本 |
| `/fixtures/steps_daily.sample-2026-09.csv` | **9月分拡張**（PDF・今日付近・未確定行を含む） |

## 前提

- **CSV が無い／対象日に行が無い／`is_final=false`** → 疲れスコア・健康生活PDFは **従来どおり**（睡眠＋予定のみ）。
- WAP では CSV 本文を `localStorage` キー `ron-sch-steps-daily-csv` に保存（本番ネイティブは `Directory.Data/steps_daily.csv`）。
- 健康生活カウント **OFF** のときは CSV を **読み込まない**（WAP への負荷・挙動変更なし）。

## 準備

1. `npm run dev` で WAP を起動しログイン。
2. 設定 → **健康生活カウント表示** を ON。
3. 月カレンダーで **2026年9月** を表示（選択日も9月内）。
4. ブラウザで次が開けることを確認:
   - `/fixtures/steps_daily.sample.csv`
   - `/fixtures/steps_daily.sample-2026-09.csv`

## 手順 A: サンプル CSV インポート

1. ホーム最下部 **健康生活カウント** を開く。
2. **CSV取込** → `steps_daily.sample.csv` を選択。
3. カレンダーで **2026-09-03** を選択。
   - 歩数 **3,200** 歩、`is_final=true` → 疲れ内訳に **歩数 n/15** が付く場合あり（不足帯）。
4. **CSV取込** → `steps_daily.sample-2026-09.csv` に差し替え（マージ）してもよい。
5. 選択月を **2026年9月** のまま **健康生活PDF** を出力し、表の **歩数・歩数加点** 列を確認（1〜10日、15〜19日などに値）。

## 手順 B: 手入力（選択日の修正）

**CSV が無い状態でも「記録」で保存用データを新規作成できます**（WAP では `localStorage` の `ron-sch-steps-daily-csv`、ネイティブでは `steps_daily.csv`）。

1. 選択日を **2026-09-19**（今日想定）または任意の9月の日。
2. 歩数入力欄に例: `5200` → **記録**。
3. 表示: `歩数: 5,200歩`（`is_final=true` の manual）。拡張 CSV 取込済みの **9/19** は manual 6800 歩で上書きされる。
4. 疲れスコアが **歩数なしのとき** と比較して変化するか確認。
5. 同じ日を `8000` に **記録** → 帯内（6000〜9000）なら歩数加点 **0** に近づく。

## 手順 C: 未確定（判定に使わない）

1. 拡張 CSV 取込後、**2026-09-20** を選択（ファイル内: `3000` 歩、`is_final=false` のみ）。
2. 表示: **（確定前・判定未反映）**、疲れは **歩数なしと同じ** であること。
3. 参考: 9/19 は `device`/`false` と `manual`/`true` が両方あるが、マージ後は **manual・6800・確定** が採用される。

## 手順 D: WAP 影響なしの確認

1. Local Storage から `ron-sch-steps-daily-csv` を削除（または未インポートの状態）。
2. 健康生活カウント OFF → ログイン〜予定操作のみ **従来通り**。
3. 健康生活カウント ON でも CSV 空 → 歩数 **未連携**（`ron-sch-steps-linked` が false のとき）、疲れ **従来式**。

## クリア（やり直し）

- **保存CSVクリア** … ブラウザに保存した歩数データだけ削除（`public/fixtures/*.csv` のサンプルファイルは **削除されません**）。
- または DevTools → Local Storage → `ron-sch-steps-daily-csv` 削除。
- クリア後も **記録** ボタン1回で、また保存用CSVを **新規作成** できます。

## ネイティブ移行時

- 同じ CSV 内容を `Filesystem` の `steps_daily.csv` に置けば、パーサ・判定は同一。
